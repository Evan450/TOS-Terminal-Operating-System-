## kernel.bootcfg

`tos/kernel/bootcfg.lua`

- `bootcfg.echoMinLevel(verbosity)`
- `bootcfg.load(fs)`
  Load /etc/boot.cfg, fail-safe. Never raises; an unreadable/corrupt file yields the `normal` defaults so boot always proceeds. @param fs table  anything with exists(path) + readFile(path)
- `bootcfg.save(fs, cfg)`
  Persist a (normalized) config back to /etc/boot.cfg. @param fs table  anything with writeFile/writeFileAtomic
- `bootcfg.verbosity(cfg)`
  Effective muter level for this config (explicit override, else profile).
- `bootcfg.shows(cfg, level)`
  True if `level` should be shown at the config's verbosity. e.g. bootcfg.shows(cfg, "text") is false on a silent/splash boot.
- `bootcfg.wants(cfg, name, ramOK)`
  Should optional feature `name` load? Resolution order: 1. an explicit advanced override (true/false), 2. the profile's pin for that feature, 3. the RAM gate (`ramOK`, default true) — today's behavior.
- `bootcfg.ramOK(cfg, detected)`
  Resolve the RAM gate: the operator's declaration wins, else the live measurement. `detected` is the caller's "free RAM looks fine" boolean.
- `bootcfg.ui(cfg, totalKB)`
  Effective startup interface: "home", "split" or "cli" -- and, as a second value, "auto" when it was chosen FOR the operator rather than set by them. "home" is the merged surface — one tab, tiles and files as two views of it, the prompt resident in both. "split" is the pre-merge shape, kept for operators who want the Desktop as its own tab. Both are the panels TUI; only "cli" is a different program. Unset is AUTO: the panels from PANELS_MIN_KB of installed memory (`totalKB`), the CLI below it, because below it the panels load and then crash the machine on the first command. ramGate = "plenty" is the operator saying the memory is fine, so it means the panels. With no `totalKB` (off-box) auto is the panels, as it always was.

## kernel.bootsettings

`tos/kernel/bootsettings.lua`

- `bootsettings.ramLabel(probe)`
  Describe the machine's installed memory for the RAM field's label, e.g. "2x T3.5". Returns nil when we can't tell (off-box unit tests, no component API), in which case the field keeps its generic wording. `probe` is injectable so the model stays testable without hardware.

  Return the editable fields with their current display values for `cfg`. @return array of { key, label, group, value(display string) } @param ramLabel string|nil  installed-memory summary for the RAM row's label (see bootsettings.ramLabel). Omitted → generic wording, which is what the pure field-model tests exercise.
- `bootsettings.cycle(cfg, idx, dir)`
  Advance field #idx of `cfg` by `dir` (+1/-1) through its value ring. Mutates and returns `cfg`. Out-of-range idx is a no-op.
- `bootsettings.cycleKey(cfg, key, dir)`
  Advance the field whose key is `key` by `dir`. Lets the runner cycle a field by identity, so the visible (filtered basic/advanced) list never has to map its row back to a full-list index. No-op on unknown key.
- `bootsettings.run(cfg, ctx)`

## kernel.compress

`tos/kernel/compress.lua`

- `compress.init(modules)`
  Detect a data card exposing deflate/inflate. Safe to call repeatedly. Uses the shared kernel.datacard detector so it agrees with crypto and the POST screen about what's installed — and, crucially, reports a card that IS present but lacks deflate/inflate honestly (instead of the old "No data card", which read as a detection failure even when crypto saw the same card as Hardware).
- `compress.available()`
  True when a data card can actually deflate/inflate on this machine.
- `compress.isPacked(blob)`
  True if `blob` is a TCZ container produced by pack().
- `compress.pack(data)`
  Compress `data` into a TCZ blob. Always returns a valid blob (never nil for a string): falls back to "stored" when there's no card, the payload is tiny, deflate fails, or the result wouldn't be smaller. @return blob string, method ("deflate"|"stored"), origBytes, packedBytes
- `compress.unpack(blob)`
  Reverse pack(). Returns the original data, or (nil, err). A "stored" blob decodes without a data card; a "compressed" blob needs one.

## kernel.hal

`tos/kernel/hal.lua`

- `hal.stickTier(kb)`
  Tier name for a SINGLE stick of `kb`, or nil when it isn't a stock size.
- `hal.ramSticks(deviceInfo)`
  Per-stick capacities in KB, largest first — or nil when the host can't tell us. This is the ONLY way to report memory honestly: totalMemory() alone cannot distinguish 2x768K from 1024K+512K (both are 1536K over two sticks), which is exactly how a T3.5+T2.5 machine got reported as "tier 3". @param deviceInfo table|nil  injected for tests; defaults to the live call
- `hal.ramSummary(sticks, totalKB, modules)`
  Human summary of installed memory: "2x T3.5", "T3.5 + T2.5", or an honest capacity when the sticks aren't stock sizes / can't be enumerated. MIXED TIERS ARE THE POINT — never average them into one tier.
- `hal.scan()`
- `hal.list(ctype)`
- `hal.primary(ctype)`
- `hal.proxy(ctype)`
- `hal.count(ctype)`
- `hal.has(ctype)`
- `hal.systemInfo()`
- `hal.freeMemory(need)`
  Free memory you can act on, rather than the first number offered. computer.freeMemory() counts UNCOLLECTED GARBAGE as used, so it only ever UNDERSTATES what is available -- never the reverse. On a real machine that is a factor of four at the end of boot: the kernel logged "Free memory: 322KB" and the same box, eighteen seconds later with nothing freed in between, reported 1268KB. Harmless in a log line. Not harmless in a GATE, and four of them read it as fact: whether the optional boot stages load, whether to shout LOW MEMORY, whether the display's dirty-cell shadow is affordable, and what the splash tells the operator they have to work with. Each one was free to answer "no" because of garbage that a collection would have thrown away. The one-directional error is what makes the fix cheap. A reading that ALREADY clears `need` is true -- that memory really is free, and no collection can produce less of it -- so the common case pays nothing. Only a reading that falls short might be an artefact, and only then is it worth collecting and asking again. Pass no `need` to mean "I want the honest number" (a report, not a gate) and always collect. Returns (bytes, collected).
- `hal.componentCount()`
- `hal.checkWireless()`
- `hal.handleComponentAdded(addr, ctype)`
- `hal.handleComponentRemoved(addr, ctype)`
- `hal.report()`

## kernel.net.mesh

`tos/kernel/net/mesh.lua`

  Build the ACK an origin expects back once delivery succeeds. The ACK floods back addressed to the original sender's node.
- `mesh.newSeen(max)`

  Record `id`; return true if it had been seen before (a duplicate). Evicts the oldest id once the cache is full so memory stays bounded.
- `mesh.seenKey(env)`
  The dedup key of an envelope: its id, plus its resend counter when it has one. A sender re-sending a message bumps the counter, so relays that saw the first flood pass the re-send on; the RECEIVER dedups delivery by the id itself (meshctl's delivered set).
- `mesh.inPath(env, addr)`
  True if `addr` already appears in the envelope's traversed path.
- `mesh.route(env, selfAddr, isForMe, seen)`
  Decide what a node at `selfAddr` should do with an arriving envelope. `isForMe(env)` -> bool: the net layer resolves whether env.to targets this node (its address, hostname, or an alias of it). `seen` is this node's dedup cache. Returns { dup, deliver, forward, out } where: dup     this id was already processed (everything else false) deliver hand the message to the local mailbox / ack handler forward re-broadcast `out` (ttl already spent, path extended) out     the envelope to re-broadcast (only when forward is true)
- `mesh.newOutbox()`
- `mesh.enqueue(ob, env, opts, now)`
  Queue an envelope for retry. `opts`: interval  seconds between re-floods (default RETRY_EVERY) deadline  absolute time after which we give up (default: never) relay     true if we're only holding a passed-through copy (shorter default deadline so relays don't hoard forever) canHold   (relay) function(bytes) -> may this node hold that much more? Default: no more than RELAY_HOLD_BYTES. `now` stamps the first attempt window. A second enqueue of the same id is ignored (keeps the original schedule). A relay copy is held only if it fits, and only the newest RELAY_HOLD_MAX are (see above).
- `mesh.ack(ob, id)`
  An ACK arrived (or we delivered locally): stop retrying this id.
- `mesh.ackRelay(ob, id)`

  Drop relay copies, oldest first, until at most `keep` remain. Returns how many went. They are a courtesy, so memory pressure takes them first.
- `mesh.dueItems(ob, now)`
  The outbox entries due at time `now`, their schedules advanced; any past their deadline are dropped. Returns (items, droppedCount).
- `mesh.due(ob, now)`
  Return the envelopes due for (re-)flooding at time `now`, advancing their schedules, and drop any past their deadline. Caller broadcasts whatever this returns.
- `mesh.pending(ob)`
  How many messages are still awaiting delivery (diagnostics / `mail` UI).

- `srm.parseArgs(args)`
  Parse an `srm` argument list into (verb, flags, paths). Lives here rather than in the shell command so it is pure and testable: the grammar has one genuinely fiddly rule, and getting it wrong turns a mount point into a file to overwrite. * the first non-flag word is the VERB (defaults to "status") * every later non-flag word is a PATH * `--flag` is a boolean; `--flag=value` carries a value * `--source <mount>` also accepts its value as the next word, and CONSUMES it BY INDEX. Matching it by value afterwards only worked when the mount happened to be the first path, so `srm restore /tos/kernel/fs.lua --source /mnt/x` tried to restore a file called /mnt/x. A `--source` with nothing to consume comes back as boolean true, which the caller reports as a usage error rather than silently ignoring.
- `srm.status(deps, opts)`
  What SRM knows right now, cheaply: the parked POST fault, whether a baseline exists and how stale it is, what the store costs, and whether the last shutdown was clean. Deliberately does NOT hash anything — this is the command an operator runs first, and it must be instant. opts.clearFault  consume the parked code (boot path does; the shell leaves it so the operator can look twice)
